# Changelog

## 1.0.0

- Soft-keyboard control for .NET MAUI on iOS and Android
- `KeyboardManager.Hide()`, `Show(entry)`, `DismissOnTapOutside()`, `SetAvoidanceMode(...)`
- Avoidance modes: System, None, Pan, Resize, SafeArea
- Visibility, height, focus, and safe-area events
- Optional `UseKeyboardManager` host registration
- Sample form and unit tests
